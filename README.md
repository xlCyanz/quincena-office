# Quincena Office

Juego de gestión de oficina en pixel art con vista isométrica. Eres el CEO de una
empresa de software: contratas, construyes tu oficina, tomas contratos y pagas la
nómina cada 15 días.

El diseño completo está en [docs/diseno.md](docs/diseno.md).

## Requisitos

- Godot 4.7.2 (estable), edición estándar (GDScript, sin .NET)

## Cómo abrirlo

1. Abre Godot y, en el gestor de proyectos, pulsa **Importar**.
2. Elige el archivo `project.godot` de la raíz de este repositorio.
3. Pulsa **F5** (o el botón ▶) para ejecutar la escena principal.

Desde la terminal en macOS:

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path . --editor
```
